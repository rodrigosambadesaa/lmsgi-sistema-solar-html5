# Enunciado / material de partida — Sistema Solar en HTML5

Práctica de **Lenguajes de Marcas** realizada en 2017 para trasladar una página temática sobre el Sistema Solar desde técnicas de HTML 4 a una estructura HTML5.

## Requisitos funcionales conservados

- Mantener el contenido informativo del Sistema Solar y la navegación entre sus apartados.
- Utilizar un documento HTML5 con codificación adecuada.
- Incorporar los recursos visuales y la presentación de la práctica.
- Mantener el formulario incluido en la página.
- Conseguir una página completa y navegable en navegador.

La entrega histórica empleaba todavía tablas de maquetación, `<font>` y atributos presentacionales (`background`, `align`, `text`, `link`, `vlink`, etc.). La versión actual conserva el ejercicio, sustituyendo esas técnicas por HTML5 semántico y CSS moderno.

> Nota: no se ha localizado junto a la entrega un PDF de enunciado independiente inequívoco; este archivo documenta únicamente el objetivo y los requisitos verificables a partir del proyecto histórico recuperado.
