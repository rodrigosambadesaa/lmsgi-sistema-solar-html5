# Enunciado de partida

Práctica de Lenguajes de Marcas realizada en 2017 para trasladar una página temática sobre el Sistema Solar desde técnicas de HTML 4 a una estructura HTML5.

La versión actual conserva la navegación y el contenido de la práctica, sustituye la maquetación heredada por HTML5 semántico y CSS responsive, y añade un backend PHP con persistencia SQLite, validación y medidas de seguridad.
